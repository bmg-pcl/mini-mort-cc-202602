How to Use

• Left strip shows thumbnails for the current file (all pages). Click to jump pages. Collapse with the link; reopen with the ☰ in the top bar.
• Draw a green rectangle; hold Alt to add multiple. Shift+click to start a polygon, click to add vertices, release Shift to close. Alt+Shift to add without replacing.
• Click a text block to toggle “Selected”.
• Esc clears selection. Ctrl+F exports filtered CSV. Ctrl+C copies visible text.
• Mouse wheel over the viewer zooms; right-mouse drag pans; “Fit” fits width.
• Shift+← / Shift+→ switches files.
